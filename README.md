# AE2 Quick Encoding Upload

This mod requires **AE2 Quick Encoding** as a prerequisite. It adds several new features: after encoding patterns with AE2 Quick Encoding, you can upload them directly to the appropriate ME Interface without having to switch back and forth between different terminals.

It also tweaks some mechanics: when you **Shift‑click** a pattern encoded by AE2 Quick Encoding inside the Interface Terminal, the mod will attempt to place it directly into a matching ME Interface, rather than the first slot in the GUI.

**Matching logic:** Patterns encoded with Quick Encoding carry an attached machine name. The mod matches this name against the ME Interface's name — meaning you can rename an ME Interface to customise which interface receives which pattern.

For **crafting patterns**, the mod will automatically place them into a pattern slot that supports crafting capabilities (e.g., the Large Molecular Assembler from *Lazy AE2*, provided you have *Lazy AE2 Patch* installed).
